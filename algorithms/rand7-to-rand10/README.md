# 用 Rand7() 构造 Rand10()

> LeetCode 470 — [Implement Rand10() Using Rand7()](https://leetcode.com/problems/implement-rand10-using-rand7/)

## 问题描述

已有方法 `rand7()` 可生成 $1 \sim 7$ 的均匀随机整数。要求利用它构造 `rand10()`，生成 $1 \sim 10$ 的均匀随机整数。

**约束**：只能调用 `rand7()`，不能使用其他随机源。

## 直觉分析

核心难点：$7$ 和 $10$ 互质，无法通过简单的线性映射（如 `rand7() % 10`）得到均匀分布。

$$P(\text{rand7() \% 10} = i) = \begin{cases} 1/7 & i \in \{1,2,3,4,5,6\} \\ 0 & i \in \{0,7,8,9\} \end{cases}$$

显然不均匀。我们需要一种方法**扩展随机范围**，然后**裁剪到目标范围**。

## 数学建模

### 扩展范围

调用两次 `rand7()`：

$$\text{num} = (\text{rand7}() - 1) \times 7 + \text{rand7}()$$

- `rand7()-1` 取 $0 \sim 6$（7 种可能）
- `rand7()` 取 $1 \sim 7$（7 种可能）
- `num` 的取值范围：$1 \sim 49$，共 $7 \times 7 = 49$ 种等概率组合

### 拒绝采样 (Rejection Sampling)

目标范围 $1 \sim 10$ 无法整除 $49$（$49 = 4 \times 10 + 9$）。

策略：
1. 若 $\text{num} \leq 40$（前 40 个数），**接受**
2. 若 $\text{num} > 40$（后 9 个数），**拒绝**，重新生成

### 为什么保持均匀？

接受条件下：

$$P(\text{num} = x \mid \text{接受}) = \frac{P(\text{num}=x)}{P(\text{接受})} = \frac{1/49}{40/49} = \frac{1}{40}$$

因此 $1 \sim 40$ 在接受条件下仍服从均匀分布。

### 映射到 $1 \sim 10$

将 $1 \sim 40$ 分成 4 组，每组 10 个数：

| 目标值 | 对应的 num |
|--------|-----------|
| 1 | 1, 11, 21, 31 |
| 2 | 2, 12, 22, 32 |
| ... | ... |
| 10 | 10, 20, 30, 40 |

映射公式：

$$\text{rand10}() = (\text{num} - 1) \bmod 10 + 1$$

## 求解过程

### 核心代码

```python
def rand10():
    while True:
        num = (rand7() - 1) * 7 + rand7()  # 1~49
        if num <= 40:
            return (num - 1) % 10 + 1
```

### 期望调用次数

每次循环调用 2 次 `rand7()`，接受概率 $40/49$。

$$E[\text{rand7 调用次数}] = 2 \times \frac{49}{40} = 2.45 \text{ 次}$$

### 优化版：扩大范围降低拒绝率

用 3 次 `rand7()` 生成 $1 \sim 343$：

```python
def rand10_optimized():
    while True:
        num = (rand7()-1)*49 + (rand7()-1)*7 + rand7()  # 1~343
        if num <= 340:
            return (num - 1) % 10 + 1
```

- 拒绝率：$3/343 \approx 0.87\%$（远低于经典的 $9/49 \approx 18.4\%$）
- 期望调用：$3 \times 343/340 \approx 3.03$ 次

> 拒绝率更低，但每次循环成本更高（3 次 vs 2 次）。实际选择取决于具体场景。

## 通用构造方法

**问题**：给定 `rand(a)`（生成 $1 \sim a$），构造 `rand(b)`（生成 $1 \sim b$）。

**解法**：

1. 找最小 $k$ 使得 $a^k \geq b$
2. 调用 $k$ 次 `rand(a)`，构造 $1 \sim a^k$ 的均匀分布
3. 拒绝大于 $\lfloor a^k / b \rfloor \times b$ 的数
4. 取模映射到 $1 \sim b$

```python
def rand_a_to_rand_b(rand_a, a, b):
    k = 1
    while a ** k < b:
        k += 1
    max_accept = (a ** k // b) * b
    while True:
        num = 0
        for _ in range(k):
            num = num * a + (rand_a() - 1)
        num += 1
        if num <= max_accept:
            return (num - 1) % b + 1
```

**期望调用次数**：

$$E = k \cdot \frac{a^k}{\lfloor a^k / b \rfloor \cdot b}$$

## 复杂度分析

| 方法 | 时间（单次） | 期望 rand7 调用 | 拒绝率 |
|------|------------|----------------|--------|
| 经典 (1~49) | $O(1)$ | 2.45 | 18.4% |
| 优化 (1~343) | $O(1)$ | 3.03 | 0.9% |

## 答案与总结

**核心代码（经典解法）**：

```python
def rand10():
    while True:
        num = (rand7() - 1) * 7 + rand7()
        if num <= 40:
            return (num - 1) % 10 + 1
```

### 核心 Insight

1. **扩展优于裁剪**：先扩大随机范围（$7 \to 49$），再裁剪到目标范围，比直接裁剪（如 `rand7() % 10`）更均匀。
2. **拒绝采样**：利用条件概率保持均匀性——在接受的子集中，每个数的条件概率仍然相等。
3. **整除是关键**：接受范围的大小必须是目标范围的整数倍（$40 = 4 \times 10$），否则映射后会出现不均匀。
4. **通用框架**：任意 `rand(a) → rand(b)` 都可用"找最小 $k$ 使 $a^k \geq b$ → $k$ 次调用 → 拒绝采样"三步解决。
