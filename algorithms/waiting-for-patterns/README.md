# 等待模式问题 — 抛硬币与收集问题

## 问题描述

### 问题 A：连续正面

不断抛一枚均匀硬币，**第一次连续抛出 $N$ 个正面**，平均需要抛多少次？

例如 $N=3$ 时，抛掷序列可能是：

```
H T H H T H H H  ← 在第 8 次首次达成连续 3 个正面
```

### 问题 B：收集所有面

投一个均匀的 $N$ 面骰，**第一次出现所有 $N$ 个面各至少一次**，平均需要投多少次？

例如 $N=6$ 时，序列可能是：

```
3 1 4 1 5 3 2 6  ← 第 8 次首次集齐 1~6
```

> 注：问题 B 即经典的 **Coupon Collector（奖券收集问题）**，本 repo 第 021 题已有详细讨论。此处作为对比，重点展示其与问题 A 的本质差异。

## 直觉分析

| | 连续正面 | 收集所有面 |
|--|---------|-----------|
| **失败后果** | 一次反面 → 全部清零 | 已收集的面不会丢失 |
| **状态记忆** | 严格的顺序约束 | 无序的集合覆盖 |
| **增长趋势** | 指数级 $O(2^N)$ | 线性对数级 $O(N\ln N)$ |

当 $N=6$ 时：
- 连续 6 次正面：期望 **126 次**
- 收集骰子 6 个面：期望仅 **14.7 次**

差距近 9 倍！因为连续正面要求每一步都不能出错，而收集问题可以"渐进积累"。

## 数学建模

### 问题 A：马尔可夫链建模

设状态 $i$ = 当前已连续抛出 $i$ 个正面。目标状态为 $N$。

$$E[i] = \text{从状态 } i \text{ 到达状态 } N \text{ 的期望次数}$$

边界条件：$E[N] = 0$

状态转移（每次抛掷）：
- 正面（概率 $1/2$）：进入状态 $i+1$
- 反面（概率 $1/2$）：回到状态 $0$

因此递推方程：

$$E[i] = 1 + \frac{1}{2} E[i+1] + \frac{1}{2} E[0], \quad i = 0, 1, \ldots, N-1$$

### 求解递推

令 $\Delta_i = E[i] - E[i+1]$，两式相减得：

$$\Delta_i = \frac{1}{2} \Delta_{i+1}$$

即 $\Delta_i$ 构成公比为 $1/2$ 的等比数列。结合边界条件递推可得：

$$\Delta_i = 2^{i+1}$$

求和：

$$E[i] = \sum_{j=i}^{N-1} \Delta_j = \sum_{j=i}^{N-1} 2^{j+1} = 2^{N+1} - 2^{i+1}$$

**最终答案**：

$$E[0] = 2^{N+1} - 2$$

验证状态值（$N=5$）：

| 状态 $i$ | $E[i]$ | 含义 |
|---------|--------|------|
| 0 | $2^6 - 2^1 = 62$ | 从零开始 |
| 1 | $2^6 - 2^2 = 60$ | 已连抛 1 个正面 |
| 2 | $2^6 - 2^3 = 56$ | 已连抛 2 个正面 |
| 3 | $2^6 - 2^4 = 48$ | 已连抛 3 个正面 |
| 4 | $2^6 - 2^5 = 32$ | 已连抛 4 个正面 |
| 5 | $0$ | 达成目标 |

### 问题 B：Coupon Collector

已收集 $k$ 个不同面时，下一次获得**新面**的概率为 $\frac{N-k}{N}$。

这是一个几何分布，期望等待次数为 $\frac{N}{N-k}$。

总期望：

$$E = \sum_{k=0}^{N-1} \frac{N}{N-k} = N \sum_{k=1}^{N} \frac{1}{k} = N \cdot H_N$$

其中 $H_N = 1 + \frac{1}{2} + \cdots + \frac{1}{N}$ 为第 $N$ 个调和数。

**最终答案**：

$$E = N \cdot H_N$$

大 $N$ 近似：$H_N \approx \ln N + \gamma + \frac{1}{2N}$，其中 $\gamma \approx 0.5772$。

## 扩展：任意模式的期望等待时间

不仅 "HH...H"，对于任意抛硬币模式（如 "HTHT"），都可用 **Conway Leading Number** 方法计算期望：

$$E(P) = \sum_{k=1}^{n} 2^k \cdot \mathbb{I}\bigl(P[0:k] = P[n-k:n]\bigr)$$

即：对所有前缀-后缀匹配的位置 $k$，累加 $2^k$。

| 模式 | 匹配位置 | 期望 |
|------|---------|------|
| H | $k=1$: H=H | $2^1 = 2$ |
| HH | $k=1$: H=H, $k=2$: HH=HH | $2+4 = 6$ |
| HTH | $k=1$: H=H, $k=3$: HTH=HTH | $2+8 = 10$ |
| HTHT | $k=2$: HT=HT, $k=4$: HTHT=HTHT | $4+16 = 20$ |

## 代码实现

### 连续正面的期望

```python
def expected_consecutive_heads(N):
    """精确解: E = 2^(N+1) - 2"""
    return 2 ** (N + 1) - 2

# DP 验证递推
def expected_consecutive_heads_dp(N):
    a = [0.0] * (N + 1)
    b = [0.0] * (N + 1)
    a[N] = b[N] = 0.0
    for i in range(N - 1, -1, -1):
        a[i] = 0.5 * a[i + 1] + 0.5
        b[i] = 1 + 0.5 * b[i + 1]
    return b[0] / (1.0 - a[0])  # E[0] = b_0 / (1-a_0)
```

### Coupon Collector

```python
def expected_coupon_collector(N):
    """E = N * H_N = N * (1 + 1/2 + ... + 1/N)"""
    return N * sum(1.0 / i for i in range(1, N + 1))
```

### Conway Leading Number（任意模式）

```python
def expected_pattern(pattern):
    n = len(pattern)
    E = 0.0
    for k in range(1, n + 1):
        if pattern[:k] == pattern[n - k:]:
            E += 2 ** k
    return E
```

## 复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 连续正面公式 | $O(1)$ | $O(1)$ |
| 连续正面 DP 验证 | $O(N)$ | $O(N)$ |
| Coupon Collector 公式 | $O(N)$ | $O(1)$ |
| Conway Leading Number | $O(N^2)$ | $O(1)$ |
| Monte Carlo 模拟 | $O(T \cdot N)$ | $O(N)$ |

## 答案与总结

| 问题 | 期望公式 | $N=3$ | $N=6$ | $N=10$ |
|------|---------|-------|-------|--------|
| 连续 $N$ 次正面 | $2^{N+1} - 2$ | 14 | 126 | 2046 |
| 收集 $N$ 个面 | $N \cdot H_N$ | 5.5 | 14.7 | 29.3 |

### 核心 Insight

1. **记忆性差异**：连续正面是**强记忆**过程（一次失败全部清零），收集问题是**弱记忆**过程（已收集的面保留）。
2. **增长差异**：前者指数增长 $O(2^N)$，后者线性对数增长 $O(N \ln N)$。
3. **Pattern Matching**：任意抛硬币模式的期望都可用 Conway Leading Number 方法在 $O(N^2)$ 内精确求解。
4. **与 Coupon Collector 的联系**：问题 B 正是本 repo 第 021 题的 Coupon Collector 问题，两者对比揭示了"顺序约束"与"集合覆盖"在期望计算中的本质区别。
