📐 核心公式推导
1. Softmax Backward
∂L/∂x = y ⊙ (dy − Σ(dy · y))
y = softmax(x), dy = dL/dy。Jacobian: ∂yᵢ/∂xⱼ = yᵢ(δᵢⱼ − yⱼ)
2. CrossEntropy + Softmax 合并
分开看时：Softmax 输出 p，CE 计算 −log(pₜ)。合并后求导，两个复杂运算竟相互抵消。
对正确类别 t：
∂L/∂xₜ = −(1/pₜ) · ∂pₜ/∂xₜ = −(1/pₜ) · pₜ(1−pₜ) = pₜ − 1
对其他类别 i ≠ t：
∂L/∂xᵢ = −(1/pₜ) · ∂pₜ/∂xᵢ = −(1/pₜ) · (−pₜpᵢ) = pᵢ
∴ dL/d(logits) = (softmax(logits) − one_hot(target)) / N
深度学习中最优美的公式：两个复杂运算合并后，梯度竟如此简单
3. MHA Backward 链
dVₕ = attnT · d(outₕ)    dAttn = d(outₕ) · VₕT
dScores = softmax_backward(dAttn, attn)
dQₕ = dScores · Kₕ / √dₖ    dKₕ = dScoresT · Qₕ / √dₖ
dX = dQ·WqT + dK·WkT + dV·WvT
