# 生日问题 (Birthday Problem)

## 问题描述

一个班级有 **50 个人**，假设每个人的生日在一年 365 天中均匀随机分布（不考虑闰年）。问：**至少有两个人生日相同的概率是多少？**

## 直觉分析

很多人第一次听到这个问题的反应是：「50 个人，365 天，概率应该很低吧？大概 10% 左右？」

但实际上这个概率高得惊人——**超过 97%**。

反直觉的原因在于：我们直觉上把问题想成了「我的生日和其他 49 个人撞上的概率」，但实际上题目问的是「**任意两个人**」之间是否存在相同的生日。比较的对数不是 49 对，而是 $C_{50}^2 = 1225$ 对！

## 数学建模

设一年有 $D = 365$ 天，班级有 $n$ 个人。

直接计算「至少一对相同」比较复杂，我们用**补集**：

$$P(\text{至少一对}) = 1 - P(\text{所有人生日都不同})$$

### 计算 P(全不同)

逐个考虑每个人的生日：
- 第 1 个人：365 天任选，概率 $365/365$
- 第 2 个人：必须和第 1 个人不同，概率 $364/365$
- 第 3 个人：必须和前 2 个人都不同，概率 $363/365$
- ……
- 第 $n$ 个人：概率 $(365-n+1)/365$

因此：

$$P(\text{全不同}) = \frac{365}{365} \times \frac{364}{365} \times \frac{363}{365} \times \cdots \times \frac{365-n+1}{365}$$

写成连乘形式：

$$P(\text{全不同}) = \prod_{i=0}^{n-1} \frac{D-i}{D} = \frac{D!}{(D-n)! \cdot D^n}$$

最终答案：

$$P(\text{至少一对}) = 1 - \prod_{i=0}^{n-1} \left(1 - \frac{i}{D}\right)$$

## 求解过程

### 代入 n = 50

$$P(\text{全不同}) = \frac{365 \times 364 \times 363 \times \cdots \times 316}{365^{50}}$$

$$P(\text{至少一对}) = 1 - P(\text{全不同}) \approx 0.9704 = 97.04\%$$

### 临界点分析

| 人数 $n$ | $P(\text{至少一对})$ |
|---------|---------------------|
| 10 | 11.69% |
| 20 | 41.14% |
| **23** | **50.73%** ⬅ 首次超过 50% |
| 30 | 70.63% |
| 40 | 89.12% |
| **50** | **97.04%** |
| 57 | 99.01% |
| 60 | 99.41% |
| 70 | 99.92% |

### 近似公式（大 D，小 n）

当 $D$ 很大时，利用 $1 - x \approx e^{-x}$（$x$ 很小时）：

$$P(\text{全不同}) = \prod_{i=0}^{n-1} \left(1 - \frac{i}{D}\right) \approx \prod_{i=0}^{n-1} e^{-i/D} = e^{-\sum_{i=0}^{n-1} i/D} = e^{-n(n-1)/(2D)}$$

因此近似公式：

$$P(\text{至少一对}) \approx 1 - e^{-n(n-1)/(2D)}$$

令 $P \approx 0.5$，解得：

$$n \approx \sqrt{2D \cdot \ln 2} \approx \sqrt{2 \times 365 \times 0.693} \approx 22.5$$

向上取整得到 **$n = 23$**，与精确解完全吻合！

## 代码实现

```python
def birthday_probability_exact(n, days=365):
    """精确计算 P(至少两人生日相同)"""
    if n > days:
        return 1.0  # 鸽巢原理

    p_all_distinct = 1.0
    for i in range(n):
        p_all_distinct *= (days - i) / days

    return 1.0 - p_all_distinct

# 50 人的概率
p = birthday_probability_exact(50)
print(f"50 人中至少两人生日相同的概率: {p*100:.2f}%")
# 输出: 97.04%
```

对数版本（避免大数溢出）：

```python
def birthday_probability_log(n, days=365):
    """用对数计算，适合大 n"""
    log_p = sum(math.log((days - i) / days) for i in range(n))
    return 1.0 - math.exp(log_p)
```

## 答案与总结

**50 人的班级中，至少有两个人同一天生日的概率约为 97.04%。**

### 关键 Insight

1. **组合爆炸**：比较的对数是 $C_n^2 = n(n-1)/2$，不是 $n-1$。当 $n=50$ 时，存在 1225 对比较。
2. **临界点极低**：只需 **23 人**，概率就超过 50%。这个数字远小于直觉估计。
3. **鸽巢原理**：当 $n > 365$ 时，概率必然为 100%（抽屉原理）。
4. **推广**：把「365 天」换成「$D$ 种可能」，把「生日」换成「哈希冲突」「ID 碰撞」等，同样的公式适用于分析哈希表冲突概率、UUID 碰撞概率等场景。
