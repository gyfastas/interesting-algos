# 坏芯片检测问题 (Faulty Chip Detection)

## 问题描述

有 $B$ 个芯片，其中**恰好有 1 个是坏的**。

你拥有的资源：
- $T$ 次测试机会
- $N$ 个检查器（一次性提供）

测试规则：
- 每轮测试，你可以将任意芯片放入任意检查器（一个检查器可以同时测多个芯片）
- 如果某检查器放入的芯片中包含坏芯片，该检查器就会**坏掉**，之后不可再用
- 如果某检查器放入的芯片全为好芯片，该检查器**完好**，之后可以继续使用
- 测试后，你能观察到哪些检查器坏掉了

**问题**：给定 $B$ 和 $T$，至少需要多少个检查器 $N$ 才能**一定**找出坏芯片？

## 直觉分析

这道题的本质是**信息论**问题：

- 坏芯片有 $B$ 种可能位置
- 每轮测试，坏芯片所在的那个检查器会坏掉，产生信息
- 坏掉的检查器告诉我们：坏芯片就在那一组中
- 没有坏的检查器告诉我们：那一组全是好芯片（可以排除）

关键观察：**每轮恰好有 1 个检查器坏掉**（因为恰好 1 个坏芯片），所以第 $t$ 轮的"信息量"等于当前可用的检查器数量。

## 数学建模

### 决策树视角

把检测过程看作一棵决策树：
- 每个内部节点代表一轮测试
- 节点的分支数 = 当前可用检查器数（哪个检查器坏掉）
- 叶子节点代表确定的坏芯片

第 1 轮：最多 $N$ 个分支（$N$ 个检查器，哪个坏？）
第 2 轮：最多 $N-1$ 个分支（1 个已坏）
第 3 轮：最多 $N-2$ 个分支
...

$T$ 轮后，叶子节点总数（总路径数）的上界为：

$$N \times (N-1) \times (N-2) \times \cdots \times (N-T+1)$$

这就是**下降阶乘**（Falling Factorial），记为 $P(N, T)$ 或 $(N)_T$。

### 信息论下界

要区分 $B$ 个芯片，需要：

$$P(N, T) = N \cdot (N-1) \cdot \cdots \cdot (N-T+1) \geq B$$

若 $T > N$，则最多只有 $N$ 轮有检查器可用（$N$ 个检查器全部坏完后无法继续），此时条件变为 $N! \geq B$。

## 求解过程

### 结论

最小检查器数 $N$ 是满足下降阶乘不等式的最小正整数：

$$\min \left\{ N \in \mathbb{Z}^+ \;:\; \prod_{i=0}^{\min(T,N)-1} (N-i) \geq B \right\}$$

### 构造性证明（路径编码策略）

下界不仅是必要的，也是充分的。构造方法如下：

**步骤 1：路径编码**

给每个芯片分配一条长度为 $T$ 的"路径" $(c_1, c_2, \ldots, c_T)$，其中 $c_t$ 表示第 $t$ 轮该芯片被放入第几个检查器。

- 第 $t$ 轮有 $(N-t+1)$ 个可用检查器
- 路径第 $t$ 位的取值范围：$c_t \in \{0, 1, \ldots, N-t\}$

总路径数 = $N \cdot (N-1) \cdot \cdots \cdot (N-T+1) = P(N, T)$

若 $P(N, T) \geq B$，则可为每个芯片分配**唯一路径**。

**编码方法**（混合进制）：

把芯片编号 $k$（$0 \leq k < B$）按混合进制展开：

$$k = c_1 + c_2 \cdot N + c_3 \cdot N(N-1) + \cdots$$

其中第 $t$ 位的基数为 $(N-t+1)$。

**步骤 2：逐轮检测**

第 $t$ 轮：
1. 将所有候选芯片按路径第 $t$ 位 $c_t$ 分组，放入对应的检查器
2. 观察哪个检查器坏掉
3. 坏检查器对应的芯片组成为新的候选集
4. 该检查器从可用池中移除

由于每个芯片的路径唯一，$T$ 轮后恰好只剩 1 个候选芯片。

### 示例

**$B=10, T=3, N=4$**

$P(4, 3) = 4 \times 3 \times 2 = 24 \geq 10$ ✓

路径编码：

| 芯片 | 路径 $(c_1, c_2, c_3)$ |
|------|------------------------|
| 0 | $(0, 0, 0)$ |
| 1 | $(1, 0, 0)$ |
| 2 | $(2, 0, 0)$ |
| 3 | $(3, 0, 0)$ |
| 4 | $(0, 1, 0)$ |
| 5 | $(1, 1, 0)$ |
| 6 | $(2, 1, 0)$ |
| 7 | $(3, 1, 0)$ |
| 8 | $(0, 2, 0)$ |
| 9 | $(1, 2, 0)$ |

假设芯片 7 是坏芯片，路径为 $(3, 1, 0)$：

- **第 1 轮**：4 个检查器，按 $c_1$ 分组 → 检查器 3 坏 → 候选集 $\{3, 7\}$
- **第 2 轮**：3 个检查器，按 $c_2$ 分组 → 检查器 1 坏 → 候选集 $\{7\}$
- **第 3 轮**：已确定，无需测试

## 代码实现

```python
def falling_factorial(N, T):
    """下降阶乘: P(N, T) = N * (N-1) * ... * (N-T+1)"""
    effective_T = min(T, N)
    prod = 1
    for i in range(effective_T):
        prod *= (N - i)
    return prod

def min_checkers(B, T):
    """二分查找最小 N 使得 P(N, T) >= B"""
    if B <= 1:
        return 0
    lo, hi = 1, max(B, T)
    ans = hi
    while lo <= hi:
        mid = (lo + hi) // 2
        if falling_factorial(mid, T) >= B:
            ans = mid
            hi = mid - 1
        else:
            lo = mid + 1
    return ans
```

### 路径编码构造策略

```python
def encode_strategy(B, N, T):
    """给每个芯片分配唯一检测路径"""
    paths = []
    for chip_id in range(B):
        path = []
        remaining = chip_id
        for t in range(T):
            base = N - t  # 第 t 轮可用检查器数
            path.append(remaining % base)
            remaining //= base
        paths.append(tuple(path))
    return paths
```

## 复杂度分析

| 操作 | 时间 | 空间 |
|------|------|------|
| 计算 $P(N, T)$ | $O(T)$ | $O(1)$ |
| 二分查找最小 $N$ | $O(\log B \cdot T)$ | $O(1)$ |
| 构造路径编码 | $O(B \cdot T)$ | $O(B \cdot T)$ |
| 模拟检测过程 | $O(T)$ | $O(1)$ |

| $B$ | $T=1$ | $T=2$ | $T=3$ | $T=4$ | $T=5$ |
|-----|-------|-------|-------|-------|-------|
| 2 | 2 | 2 | 2 | 2 | 2 |

| 50 | 50 | 8 | 5 | 5 | 5 |
| 100 | 100 | 11 | 6 | 5 | 5 |
| 120 | 120 | 11 | 6 | 5 | 5 |

观察：
- $T=1$ 时，需要 $N=B$（每个检查器测 1 个芯片）
- $T$ 增加时，$N$ 迅速下降（信息复用）
- $T \geq N$ 后，多余的测试轮次不再减少 $N$（检查器已耗尽）

## 答案与总结

**给定 $B$ 个芯片和 $T$ 次测试，至少需要 $N$ 个检查器，其中 $N$ 是满足：**

$$N \cdot (N-1) \cdot \cdots \cdot (N-T+1) \geq B$$

**的最小正整数。**

### 核心 Insight

1. **信息复用**：检查器坏掉本身传递信息（坏芯片在哪个组），因此坏掉的检查器"物有所值"。
2. **下降阶乘**：每轮可用检查器递减，总信息量为下降阶乘 $P(N, T)$。
3. **构造可达**：路径编码策略证明了下界是紧的（tight bound）。
4. **与二分搜索的对比**：如果检查器不会坏掉，$T$ 轮可区分 $2^T$ 个芯片；检查器会坏掉反而提供更多结构化信息（每轮恰坏 1 个），使得 $T$ 轮 + $N$ 个检查器可区分 $P(N, T) = N!/(N-T)!$ 种情况。
