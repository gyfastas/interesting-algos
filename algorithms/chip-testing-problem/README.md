# 坏芯片检测问题 (Faulty Chip Detection)

> 等价于 LeetCode 458 [可怜的猪](https://leetcode.com/problems/poor-pigs/)

## 问题描述

有 $B$ 个芯片，其中**恰好有 1 个是坏的**。

你拥有的资源：
- $T$ 轮测试机会
- $N$ 个检查器

测试规则：
- 每轮测试中，你可以将任意芯片放入任意检查器（一个检查器可以同时测多个芯片，一个芯片可以同时放入多个检查器）
- 本轮测试结束后，如果某检查器放入的芯片中包含坏芯片，该检查器就会**坏掉**，之后不可再用
- 如果某检查器放入的芯片全为好芯片，该检查器**完好**，下一轮可以继续使用
- 每轮测试后，你能观察到哪些检查器坏掉了

**问题**：给定 $B$ 和 $T$，至少需要多少个检查器 $N$ 才能**一定**找出坏芯片？

## 直觉分析

这道题的本质是**信息编码**问题：

- 每个检查器在多轮测试中，最终状态有 $(T+1)$ 种可能：
  - 第 1 轮后坏
  - 第 2 轮后坏
  - ...
  - 第 $T$ 轮后坏
  - 始终没坏

- $N$ 个检查器可以产生 $(T+1)^N$ 种不同的状态组合
- 每种状态组合对应唯一的坏芯片
- 因此需要状态空间足够大：$(T+1)^N \geq B$

> 注意：与"下降阶乘"模型的本质区别在于，这里一个芯片可以被放入**多个检查器**（重叠测试），一个检查器可以在**多轮中使用**直到坏掉。

## 数学建模

### 信息论下界

$N$ 个检查器，$T$ 轮测试，每个检查器最终有 $(T+1)$ 种状态。

$$\text{总状态数} = (T+1)^N$$

要区分 $B$ 个芯片中的坏芯片：

$$(T+1)^N \geq B$$

取对数：

$$N \geq \frac{\ln B}{\ln (T+1)}$$

因为 $N$ 是整数：

$$N = \left\lceil \frac{\ln B}{\ln (T+1)} \right\rceil$$

### 构造性证明：$(T+1)$ 进制编码

下界不仅是必要的，也是充分的。构造方法如下：

**步骤 1：编码**

把芯片编号 $0 \sim B-1$ 用 **$(T+1)$ 进制**表示，需要 $N$ 位：

$$k = d_0 + d_1 \cdot (T+1) + d_2 \cdot (T+1)^2 + \cdots + d_{N-1} \cdot (T+1)^{N-1}$$

其中 $d_i \in \{0, 1, \ldots, T\}$。

**步骤 2：设计测试方案**

检查器 $i$（对应第 $i$ 位 $d_i$）：
- 第 $t$ 轮（$1 \leq t \leq T$）：测所有满足 $d_i = t$ 的芯片
- 若 $d_i = 0$：该检查器**从不测**这个芯片

**步骤 3：解码**

测试结束后：
- 检查器 $i$ 始终没坏 $\Rightarrow d_i = 0$
- 检查器 $i$ 第 $t$ 轮后坏 $\Rightarrow d_i = t$

组合 $(d_0, d_1, \ldots, d_{N-1})$ 即得芯片编号。

### 示例

**$B=9, T=2, N=2$**

$(T+1)^N = 3^2 = 9 \geq 9$ ✓

$(T+1)=3$ 进制编码：

| 芯片 | $(d_0, d_1)$ | 十进制 |
|------|-------------|--------|
| 0 | $(0, 0)$ | $0 + 0 \cdot 3 = 0$ |
| 1 | $(1, 0)$ | $1 + 0 \cdot 3 = 1$ |
| 2 | $(2, 0)$ | $2 + 0 \cdot 3 = 2$ |
| 3 | $(0, 1)$ | $0 + 1 \cdot 3 = 3$ |
| 4 | $(1, 1)$ | $1 + 1 \cdot 3 = 4$ |
| 5 | $(2, 1)$ | $2 + 1 \cdot 3 = 5$ |
| 6 | $(0, 2)$ | $0 + 2 \cdot 3 = 6$ |
| 7 | $(1, 2)$ | $1 + 2 \cdot 3 = 7$ |
| 8 | $(2, 2)$ | $2 + 2 \cdot 3 = 8$ |

**测试方案**：

- **检查器 0**（看 $d_0$）：
  - 第 1 轮测 $d_0=1$ 的芯片：$\{1, 4, 7\}$
  - 第 2 轮测 $d_0=2$ 的芯片：$\{2, 5, 8\}$

- **检查器 1**（看 $d_1$）：
  - 第 1 轮测 $d_1=1$ 的芯片：$\{3, 4, 5\}$
  - 第 2 轮测 $d_1=2$ 的芯片：$\{6, 7, 8\}$

**假设芯片 4 是坏芯片**（编码 $(1, 1)$）：

- 第 1 轮：检查器 0 测了芯片 4（$d_0=1$）→ 坏；检查器 1 测了芯片 4（$d_1=1$）→ 坏
- 第 2 轮：两个检查器都已坏，无法继续测
- 解码：检查器 0 第 1 轮坏 $\Rightarrow d_0=1$；检查器 1 第 1 轮坏 $\Rightarrow d_1=1$
- 组合：$(1, 1)$ → $1 + 1 \times 3 = 4$ ✓

**假设芯片 8 是坏芯片**（编码 $(2, 2)$）：

- 第 1 轮：两个检查器都没测芯片 8（$d_0=2, d_1=2$，都是第 2 轮才测）
- 第 2 轮：检查器 0 测了芯片 8 → 坏；检查器 1 测了芯片 8 → 坏
- 解码：检查器 0 第 2 轮坏 $\Rightarrow d_0=2$；检查器 1 第 2 轮坏 $\Rightarrow d_1=2$
- 组合：$(2, 2)$ → $2 + 2 \times 3 = 8$ ✓

## 代码实现

```python
import math

def min_checkers(B, T):
    """
    最小 N 满足 (T+1)^N >= B
    即 N = ceil(log(B) / log(T+1))
    """
    if B <= 1:
        return 0
    if T == 0:
        return B
    return math.ceil(math.log(B) / math.log(T + 1))


def encode_strategy(B, N, T):
    """
    (T+1) 进制编码策略。
    返回 strategy[chip_id][i] = 检查器 i 应在第几轮测该芯片。
    值为 0 表示该检查器从不测此芯片。
    """
    base = T + 1
    strategy = []
    for chip_id in range(B):
        digits = []
        x = chip_id
        for _ in range(N):
            digits.append(x % base)
            x //= base
        strategy.append(digits)
    return strategy
```

## 复杂度分析

| 操作 | 时间 | 空间 |
|------|------|------|
| 计算最小 $N$ | $O(1)$ | $O(1)$ |
| 构造编码策略 | $O(B \cdot N)$ | $O(B \cdot N)$ |
| 模拟检测过程 | $O(B \cdot N + T \cdot N)$ | $O(1)$ |

观察：
- $T$ 增加时，$N$ 迅速下降（指数级效率提升）
- $T=1$ 时，$N = \lceil \log_2 B \rceil$，等价于二进制编码
- $T=15, B=1000$ 时，仅需 $N=3$ 个检查器！

## 答案与总结

**给定 $B$ 个芯片和 $T$ 轮测试，至少需要 $N$ 个检查器：**

$$N = \left\lceil \frac{\ln B}{\ln (T+1)} \right\rceil$$

### 核心 Insight

1. **状态空间**：每个检查器有 $(T+1)$ 种最终状态，$N$ 个检查器可编码 $(T+1)^N$ 种组合。
2. **进制编码**：用 $(T+1)$ 进制表示芯片编号，检查器 $i$ 负责解码第 $i$ 位。
3. **重叠测试**：一个芯片可以同时放入多个检查器（编码中多位非零），这是信息量远超"下降阶乘"模型的关键。
4. **与 LeetCode 458 的对应**：
   - 检查器 ↔ 猪
   - 芯片 ↔ 水桶
   - 坏芯片 ↔ 毒药水
   - $T$ 轮 ↔ `minutesToTest / minutesToDie`
   - 检查器坏掉 ↔ 猪死亡
