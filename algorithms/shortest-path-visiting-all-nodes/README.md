# 访问所有节点的最短路径

> LeetCode 847 · Hard · 图论、状态压缩、BFS

## 问题描述

给定一个无向连通图，包含 $n$ 个节点（编号 $0$ 到 $n-1$）。找到一条**最短路径**，使得路径上的节点覆盖所有 $n$ 个节点至少一次。可以重复访问节点和边。

> **示例**
> - `graph = [[1,2,3],[0],[0],[0]]` → 最短路径长度 `4`
>   - 解释：路径 `1 → 0 → 2 → 0 → 3`，共 4 条边
> - `graph = [[1],[0,2,4],[1,3,4],[2],[1,2]]` → 最短路径长度 `4`

## 直觉分析

这道题和「旅行商问题（TSP）」很像，但有三个关键区别：
1. **图不是完全图**——不是所有节点对之间都有边
2. **允许重复访问**——可以走回头路
3. **不需要回到起点**——路径的起点和终点可以不同

### 为什么不能直接 DP？

如果图是完全图，TSP 可以用状态压缩 DP：$dp[mask][i]$ 表示从某个起点出发，访问了 $mask$ 中的节点，当前在 $i$ 的最短距离。

但这里图不是完全图，$i$ 到 $j$ 可能没有直连边。不过允许重复访问意味着：即使没有直连边，也可以通过中间节点走过去。所以本质上，任意两点之间都有"路径"（只是长度不同）。

**关键洞察**：最短路径一定不会出现「绕路」的情况——如果已经访问了某组节点，当前在某个节点，下一步一定是走到某个邻居。因此状态可以简洁地表示为：

> **(已访问节点集合, 当前所在节点)**

## 数学建模

### 状态定义

- `mask`: 一个 $n$ 位二进制数，第 $i$ 位为 1 表示节点 $i$ 已被访问
- `u`: 当前所在的节点编号
- `dist[mask][u]`: 从某个起点出发，访问集合为 $mask$ 且当前在 $u$ 的最短路径长度

初始状态：对于每个节点 $i$，$(mask=2^i, u=i)$，距离为 0。

### 状态转移

从状态 $(mask, u)$ 可以走到邻居 $v$：

$$
(mask, u) \xrightarrow{\text{走边 } (u,v)} (mask \;|\; 2^v, \; v)
$$

新距离 = 原距离 + 1。

### 目标状态

$$
mask = 2^n - 1 \quad \text{(所有位都是 1)}
$$

## 求解过程

### 状态压缩 BFS

由于每条边的权重都是 1，**BFS 天然适合求最短路**。我们把 $(mask, u)$ 看作 BFS 中的一个"状态节点"：

```
初始化队列：所有 (1<<i, i)，距离为 0

while 队列非空:
    (mask, u) = 队首出队
    if mask == (1<<n) - 1:
        返回当前距离
    for v in graph[u]:
        new_mask = mask | (1<<v)
        if dist[new_mask][v] 未被访问:
            dist[new_mask][v] = dist[mask][u] + 1
            入队 (new_mask, v)
```

### 为什么同时从所有节点出发？

这道题**起点不固定**。我们不知道最优路径从哪个节点开始，所以同时把 $n$ 个节点都作为起点入队。BFS 的层次遍历保证第一次遇到 `mask == (1<<n)-1` 时，距离就是全局最优解。

### 复杂度分析

- **状态总数**：$O(2^n \cdot n)$，每个节点搭配 $2^n$ 个访问集合
- **每个状态的转移**：最多 `degree(u)` 个邻居
- **总时间**：$O(2^n \cdot n \cdot \text{avg\_degree}) \approx O(2^n \cdot n^2)$
- **总空间**：$O(2^n \cdot n)$

> $n=12$ 时，状态数约 5 万，BFS 轻松处理；$n=20$ 时，状态数约 2000 万，内存压力较大。

## 代码实现

```python
from collections import deque

def shortest_path_length(graph):
    n = len(graph)
    if n == 1:
        return 0

    target = (1 << n) - 1
    dist = [[-1] * n for _ in range(1 << n)]
    q = deque()

    # 同时从所有节点出发
    for u in range(n):
        mask = 1 << u
        dist[mask][u] = 0
        q.append((mask, u))

    while q:
        mask, u = q.popleft()
        d = dist[mask][u]

        if mask == target:
            return d

        for v in graph[u]:
            new_mask = mask | (1 << v)
            if dist[new_mask][v] == -1:
                dist[new_mask][v] = d + 1
                q.append((new_mask, v))

    return -1
```

## 答案与总结

**核心 Insight**：把「路径问题」转化为「状态空间上的最短路径问题」。状态 = (已访问集合, 当前位置)，转移 = 走到邻居并更新访问集合。

**关键点**：
1. **同时从所有节点出发**——起点不固定，全部入队保证找到全局最优
2. **BFS 天然适合**——所有边权重为 1，层次遍历即最短距离
3. **位运算加速**——`mask | (1<<v)` 是 $O(1)$ 的状态更新

**复杂度**：
- 时间：$O(2^n \cdot n^2)$
- 空间：$O(2^n \cdot n)$

**一句话总结**：这道题是状态压缩 BFS 的经典应用——把「访问集合」编码到状态里，BFS 一遍即可求出覆盖全图的最短路径。
