最长路径: - 已计算: 0 点击单元格: 查看从该点出发的路径
核心思路
状态: dp[i][j] = 从 (i,j) 出发的最长递增路径长度
转移: dp[i][j] = 1 + max(dp[ni][nj])，其中 matrix[ni][nj] > matrix[i][j]
lru_cache: @functools.lru_cache(maxsize=None) 自动缓存函数返回值
手写 memo: 二维数组 dp[i][j]，计算前检查是否为 0
关键: 只能向严格更大的值移动 → 天然无环 → 每个单元格只计算一次
