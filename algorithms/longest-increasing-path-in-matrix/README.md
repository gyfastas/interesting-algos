# 矩阵中的最长递增路径

> LeetCode 329 · Hard · 动态规划、记忆化搜索、DFS · ⭐⭐⭐⭐

## 问题描述

给定一个 $m \times n$ 的整数矩阵，找到其中最长的递增路径。路径中的每个单元格可以向上、下、左、右四个方向移动，且只能移动到值**严格更大**的相邻单元格。

> **示例**
> ```
> 矩阵: [[9,9,4],
>        [6,6,8],
>        [2,1,1]]
> 最长递增路径: 1 → 2 → 6 → 9，长度 = 4
> ```

## 直觉分析

### 暴力 DFS 的问题

对每个单元格做一次 DFS，向四个方向探索递增路径。时间复杂度是多少？

如果没有记忆化，每个 DFS 可能遍历 $O(2^{mn})$ 条路径——因为可以走到任意长的路径上。这太慢了。

### 关键观察：无环性

由于只能向**严格更大**的值移动，路径上不可能出现环（否则会出现 $a \to b \to \dots \to a$，但 $a < b < \dots < a$ 矛盾）。

这意味着：从任意单元格出发，最多走 $mn$ 步就会停下来。更妙的是——**从 (i,j) 出发的最长路径只依赖于它的更大邻居，与访问顺序无关**。

### 记忆化搜索

设 $dp[i][j]$ = 从 $(i,j)$ 出发的最长递增路径长度。则：

$$
dp[i][j] = 1 + \max_{(ni,nj) \text{ 是更大邻居}} dp[ni][nj]
$$

如果 $(i,j)$ 的所有邻居都不更大，则 $dp[i][j] = 1$（只有自己）。

**为什么不会重复计算？** 因为值严格递增，$dp[i][j]$ 只依赖于值更大的单元格，而这些单元格的 $dp$ 值会先被计算出来（递归的自然顺序）。

## 数学建模

### 状态定义

$$
dp[i][j] = \text{从 } (i,j) \text{ 出发的最长递增路径长度}
$$

### 状态转移

$$
dp[i][j] = \max\left\{ 1, \; 1 + dp[ni][nj] \;\middle|\; (ni,nj) \in \text{neighbors}(i,j), \; matrix[ni][nj] > matrix[i][j] \right\}
$$

### 答案

$$
\text{ans} = \max_{i,j} dp[i][j]
$$

## 求解过程

### 方法一：@lru_cache() 装饰器版

Python 的 `functools.lru_cache` 可以自动缓存函数返回值：

```python
@functools.lru_cache(maxsize=None)
def dfs(i, j):
    best = 1
    for di, dj in [(-1,0), (1,0), (0,-1), (0,1)]:
        ni, nj = i + di, j + dj
        if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
            best = max(best, 1 + dfs(ni, nj))
    return best
```

> **注意**：`lru_cache` 要求参数可哈希，所以 `matrix` 需要转成 `tuple(tuple(row) for row in matrix)`。

### 方法二：手写 memo 版

用二维数组 `dp[i][j]` 手动管理缓存：

```python
def dfs(i, j):
    if dp[i][j] != 0:
        return dp[i][j]
    best = 1
    for di, dj in directions:
        ni, nj = i + di, j + dj
        if 0 <= ni < m and 0 <= nj < n and matrix[ni][nj] > matrix[i][j]:
            best = max(best, 1 + dfs(ni, nj))
    dp[i][j] = best
    return best
```

### 方法三：拓扑排序（BFS 逐层剥离）

从所有"局部最大值"（没有比它更大的邻居）开始，逆向 BFS 逐层剥离：

1. 计算每个点的出度（可以向几个更大的邻居走）
2. 出度为 0 的点入队（它们是路径的终点）
3. 逆向剥离：处理一个点时，所有比它小的邻居的出度减 1
4. BFS 的层数即为最长路径长度

> 拓扑排序的优点：**无递归**，不受 Python 递归深度限制。

### 三种方法对比

| 方法 | 代码量 | 速度 | 特点 |
|------|--------|------|------|
| `@lru_cache()` | 15 行 | 中等 | 最简洁，自动缓存 |
| 手写 memo | 25 行 | **最快** | 纯数组访问，无哈希开销 |
| 拓扑排序 | 35 行 | 较慢 | **无递归**，适合极大矩阵 |

## 答案与总结

**核心 Insight**：矩阵中的最长递增路径 = **在有向无环图（DAG）上求最长路径**。由于只能向严格更大的值移动，天然形成 DAG，因此可以用记忆化搜索或拓扑排序高效求解。

**关键点**：
1. **无环性**保证了解的存在性和唯一性
2. **记忆化**让每个单元格只被计算一次
3. `lru_cache` 最优雅，手写 memo 最快，拓扑排序最稳

**复杂度**：
- 时间：$O(m \cdot n)$，每个单元格计算一次
- 空间：$O(m \cdot n)$，memo 数组

**一句话总结**：把矩阵看成 DAG（边从小值指向大值），问题转化为 DAG 最长路径——记忆化搜索或拓扑排序均可 $O(mn)$ 解决。
