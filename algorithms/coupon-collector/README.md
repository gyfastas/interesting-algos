# 集齐十二星座 / 优惠券收集问题

> Coupon Collector's Problem · 概率论 · 期望 · ⭐⭐⭐

## 问题描述

假设你每次遇到一个人，他的星座在十二星座中均匀随机分布。问：平均需要遇到多少人，才能集齐全部十二星座？

更一般地：有 $N$ 种不同的奖券，每次随机抽取一张（每种概率均为 $1/N$），集齐所有 $N$ 种奖券平均需要多少次抽取？

> **示例**
> - 你买了一箱方便面，里面有 5 种口味，每包随机一种。平均要买多少包才能尝到全部口味？
> - 某 APP 有 12 种数字藏品，每次签到随机送一种。平均要签到多少次才能集齐？

## 直觉分析

很多人第一反应是"大概 $N$ 次吧"——比如 12 个星座，猜 12 个人。但这严重低估了。

直觉上：
- **第一个**星座：第一次遇到的人肯定是新的，只需 1 人
- **第二个**星座：还有 11/12 的概率遇到新的，平均等 12/11 ≈ 1.09 人
- **最后一个**星座：只剩下 1/12 的概率遇到缺失的那个，平均要等 **12 次**！

所以总期望不是 12，而是 $1 + 12/11 + 12/10 + \dots + 12/1 \approx 37.24$。

> **关键洞察**：收集过程越往后越慢，因为"遇到新东西"的概率越来越低。最后的 10% 往往需要超过 50% 的总时间。

## 数学建模

### 随机变量分解

设 $T$ 为集齐全部 $N$ 种奖券所需的总抽取次数。将 $T$ 分解为 $N$ 个阶段的和：

$$
T = T_1 + T_2 + \dots + T_N
$$

其中 $T_k$ 表示：**已经收集了 $k-1$ 种后，抽到第 $k$ 种新奖券所需的额外次数**。

### 几何分布

当已经拥有 $k-1$ 种时，每次抽取：
- 抽到新奖券的概率：$p_k = \dfrac{N - (k-1)}{N} = \dfrac{N-k+1}{N}$
- 抽到已集齐的概率：$1 - p_k = \dfrac{k-1}{N}$

因此 $T_k$ 服从几何分布：

$$
T_k \sim \text{Geometric}(p_k)
$$

几何分布的期望和方差：

$$
E[T_k] = \frac{1}{p_k} = \frac{N}{N-k+1}, \quad \text{Var}(T_k) = \frac{1-p_k}{p_k^2} = \frac{N(k-1)}{(N-k+1)^2}
$$

## 求解过程

### 期望的计算

由于各阶段相互独立（每次抽取都是独立同分布的），期望可线性分解：

$$
E[T] = \sum_{k=1}^{N} E[T_k] = \sum_{k=1}^{N} \frac{N}{N-k+1}
$$

令 $j = N-k+1$，则：

$$
E[T] = N \sum_{j=1}^{N} \frac{1}{j} = N \cdot H_N
$$

其中 $H_N = 1 + \dfrac{1}{2} + \dfrac{1}{3} + \dots + \dfrac{1}{N}$ 是第 $N$ 个**调和数**。

### 方差的计算

同理，各阶段方差相加：

$$
\text{Var}(T) = \sum_{k=1}^{N} \text{Var}(T_k) = \sum_{k=1}^{N} \frac{N(k-1)}{(N-k+1)^2}
$$

令 $j = N-k+1$：

$$
\text{Var}(T) = \sum_{j=1}^{N} \frac{N(N-j)}{j^2} = N^2 \sum_{j=1}^{N} \frac{1}{j^2} - N \sum_{j=1}^{N} \frac{1}{j} = N^2 H_N^{(2)} - N H_N
$$

其中 $H_N^{(2)} = 1 + \dfrac{1}{2^2} + \dots + \dfrac{1}{N^2}$ 是二阶调和数。

### 大 $N$ 近似

当 $N$ 很大时，调和数有经典渐近展开：

$$
H_N = \ln N + \gamma + \frac{1}{2N} - \frac{1}{12N^2} + O\left(\frac{1}{N^4}\right)
$$

其中 $\gamma \approx 0.57721566$ 是 **Euler-Mascheroni 常数**。因此：

$$
E[T] = N \ln N + \gamma N + \frac{1}{2} + O\left(\frac{1}{N}\right)
$$

这个近似在 $N \ge 10$ 时已经相当精确（误差 < 0.1%）。

### 十二星座的精确答案

$$
E[T] = 12 \times H_{12} = 12 \times \left(1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{12}\right) \approx 37.24
$$

分步拆解：

| 阶段 $k$ | 已有种类 | 新概率 $p_k$ | 期望等待 $E[T_k]$ |
|---------|---------|-------------|------------------|
| 1 | 0 | 1.0000 | 1.00 |
| 2 | 1 | 0.9167 | 1.09 |
| ... | ... | ... | ... |
| 11 | 10 | 0.1667 | 6.00 |
| 12 | 11 | 0.0833 | **12.00** |
| **总计** | | | **37.24** |

## 代码实现

```python
def harmonic_number(n):
    """第 n 个调和数。"""
    return sum(1.0 / i for i in range(1, n + 1))

def coupon_collector_expectation(n):
    """集齐 N 种奖券的期望抽取次数。"""
    return n * harmonic_number(n)

def coupon_collector_approximation(n):
    """大 N 近似：N ln N + γN + 1/2"""
    gamma = 0.5772156649015329
    return n * math.log(n) + gamma * n + 0.5

# N = 12（十二星座）
n = 12
print(f"精确期望: {coupon_collector_expectation(n):.2f}")
print(f"大 N 近似: {coupon_collector_approximation(n):.2f}")
# → 精确期望: 37.24
# → 大 N 近似: 37.25
```

## 答案与总结

**核心 Insight**：优惠券收集问题的本质是**一系列难度递增的几何分布之和**。每收集一个新奖券，"中奖概率"就降低一档，导致后期的等待时间呈指数级拉长。

**关键公式**：

$$
\boxed{E[T] = N \cdot H_N = N \left(1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{N}\right) \approx N \ln N + \gamma N}
$$

**重要结论**：
1. 集齐 12 星座平均需要遇到 **约 37 人**，而非直觉的 12 人
2. 集齐 365 种生日平均需要 **约 2365 人**（约 6.5 倍于一年天数）
3. 最后一种奖券的期望等待时间等于 $N$，占总时间的约 $1/\ln N$ 比例
4. 方差约为 $N^2 \cdot \pi^2/6$，标准差与期望值同阶

**复杂度**：
- 精确计算：$O(N)$（计算调和数）
- 近似计算：$O(1)$（用对数公式）
- Monte Carlo 模拟：$O(R \cdot N \ln N)$，$R$ 为模拟轮数
