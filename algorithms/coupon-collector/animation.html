📐 理论推导
核心思想：将总等待时间分解为 N 个独立的几何分布之和。 设 Tₖ 为已经收集 k−1 种后，抽到第 k 种新奖券所需的额外次数。 此时每次抽到新奖券的概率为 pₖ = (N−k+1)/N，因此 Tₖ ~ Geometric(pₖ)，期望 E[Tₖ] = 1/pₖ = N/(N−k+1)。
由期望的线性性：
E[T] = E[T₁] + E[T₂] + … + E[Tₙ] = N · HN
其中 HN = 1 + 1/2 + 1/3 + … + 1/N 为第 N 个调和数
大 N 近似（Euler-Mascheroni 常数 γ ≈ 0.5772）：
E[T] ≈ N ln N + γN + 0.5
分步拆解（当前 N = 12）： 最后一个奖券平均需要等 N = 12 次，占总时间的约 1/ln N ≈ 40%。
